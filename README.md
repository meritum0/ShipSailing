# Sailing Game
A small Unity 6 project about sailing a ship with just two controls: how far the sail is open (0–100%) and how far it is rotated (±45°). The ship is moved by a hand-written simulation of wind, sail, keel and water drag. There is no Rigidbody and there are no colliders.

## Controls
Key	Action

W / S	- Open / close the sail

Q / E	- Rotate the sail left / right

A / D	- Rudder left / right (works only while the ship is moving)
